# Praktikum 4 PBO - Sistem Manajemen Aset IT

## Deskripsi

Program Sistem Manajemen Aset IT dibuat untuk memenuhi tugas Praktikum Pemrograman Berorientasi Objek (PBO) Modul 4.

Program ini digunakan untuk mengelola data aset IT menggunakan bahasa Java.

## Konsep yang Digunakan

- Class dan Object
- Constructor
- ArrayList
- For-Each
- Iterator
- CRUD dasar
